# 🎯 Institutional Market Depth Sniper Bot (بوت قناص عمق السوق العالمي)

بوت تداول فائق الدقة متخصص في أسواق **الذهب (XAU/USD)** و **الفوركس (FX)**، يعتمد على **البنية الدقيقة لدفتر الأوامر (Market Microstructure / Level 2 Order Book)** لتحليل السيولة المؤسساتية واقتناص الصفقات مع تحديد كامل لنقاط الدخول، وقف الخسارة، والأهداف، ثم إرسالها فوراً إلى قناتك أو حسابك على تليجرام.

---

## 🔬 كيف يحلل البوت عمق السوق كالمحترفين العالميين؟

1. **مؤشر عدم التوازن (Order Book Imbalance - OBI):**
   يقيس النسبة الدقيقة لتفوق المشترين على البائعين (أو العكس) عبر المعادلة:
   $$\text{OBI} = \frac{\sum \text{Bid Volumes} - \sum \text{Ask Volumes}}{\sum \text{Bid Volumes} + \sum \text{Ask Volumes}}$$
   ولا يتدخل البوت إلا عندما يتجاوز هذا الاختلال عتبة **65% إلى 70%** في اتجاه الصفقة.

2. **السعر اللحظي العادل (Micro-Price):**
   يحسب السعر المرجح بالأحجام في أعلى طبقات الدفتر لمعرفة انزياح السعر قبل حدوثه على الشموع اليابانية.

3. **جدران السيولة المؤسساتية (Liquidity Walls):**
   يكتشف أوامر الشراء والبيع الضخمة (الحيتان وصناع السوق) ويعتمدها كدروع دعم ومقاومة.

4. **تحديد المستويات بدقة:**
   * **سعر ومنطقة الدخول:** الدخول بالتزامن مع امتصاص السيولة.
   * **وقف الخسارة (Stop Loss):** يُوضع بطريقة ذكية **خلف جدار السيولة مباشرة** + هامش أمان، ليكون محمياً بجدار طلبات يصعب على السعر اختراقه.
   * **الأهداف (Take Profit):** عند جدران السيولة المقابلة لتحقيق نسبة عائد إلى مخاطرة تفوق $1:2$ أو $1:3$.

## 🚀 كيفية التثبيت والتشغيل

### 1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

### 2. إعداد تليجرام:
1. تحدث مع `@BotFather` على تليجرام وأنشئ بوتاً جديداً للحصول على **`TELEGRAM_BOT_TOKEN`**.
2. للحصول على معرفك أو معرف القناة **`TELEGRAM_CHAT_ID`**، يمكنك مراسلة `@userinfobot` أو إرسال رسالة في القناة.
3. افتح ملف `config.py` أو أنشئ ملف `.env` وضع بياناتك:
```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRstuvWxyz
TELEGRAM_CHAT_ID=987654321
```

### 3. تشغيل البوت:
```bash
python main.py
```

---

## 📁 هيكلية ملفات المشروع:
* `config.py`: إعدادات الحساب، الأصول، عتبة الـ OBI، ومضاعفات السيولة.
* `orderbook_engine.py`: العقل الرياضي المتقدم لتحليل دفتر الأوامر.
* `market_feed.py`: مزود تدفق بيانات عمق السوق للذهب والعملات.
* `telegram_notifier.py`: تصميم وتنسيق وإرسال التوصيات الشاملة لتليجرام.
* `main.py`: حلقة المراقبة والاقتناص اللحظي.
